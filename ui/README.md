# The Ancient — HUD

Next.js war-room UI for [The Ancient](https://github.com/JayroldSoriano/the-ancient).

Created by [Jayrold Christian Soriano](https://github.com/JayroldSoriano).

```bash
cp apps/web/.env.example apps/web/.env.local
# NEXT_PUBLIC_API_URL=http://localhost:2024
# NEXT_PUBLIC_ASSISTANT_ID=ancient

cd apps/web
npm install
npm run dev -- --port 3000
```

Open http://localhost:3000. The graph must already be running on port 2024.
